# Mechanical POS System

An AI-powered Point of Sale (POS) system designed for mechanical shops and spare parts stores.

## Overview

Mechanical POS System is a Windows desktop application built with C# and .NET 8 using WPF.

The goal of this project is to develop a modern POS solution that helps mechanical shops manage products, sales, inventory, and payments efficiently.

This project is currently under development.

## Tech Stack

- **Language:** C#
- **Framework:** .NET 8
- **UI:** Windows Presentation Foundation (WPF)
- **IDE:** Visual Studio 2022
- **Version Control:** Git & GitHub

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/Exit-Hacker/MechanicalPosSystem.git
```

2. Open `MechanicalPosSystem.slnx` in Visual Studio 2022.

3. Restore NuGet packages.

4. Build and run the project.
